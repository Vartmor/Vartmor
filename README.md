## About

Computer Engineering student at **Gazi University**, building production-minded software at the intersection of **AI systems** and **full stack product engineering**.

- **Software Engineering** — Clean architecture, OOP and design patterns, data structures & algorithms, and maintainable codebases across Python, TypeScript, Java, C#, C and Rust.

## Featured Projects

<details open>
<summary><b>CADLift — Prompt & Drawing to Production-Ready 3D Geometry</b></summary>

<br/>

Open-source engine that converts natural language prompts, images and 2D DWG/DXF drawings into production-ready 3D geometry, compatible with AutoCAD, FreeCAD, Blender and Unity.

| | |
| :--- | :--- |
| **Stack** | ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![LLM](https://img.shields.io/badge/LLM-412991?style=flat-square&logo=openai&logoColor=white) ![CAD](https://img.shields.io/badge/DWG%2FDXF-7C3AED?style=flat-square) |
| **Scale** | Multi-format CAD interoperability across four major 3D toolchains |
| **Performance** | Deterministic geometry pipeline built on reusable parametric primitives |
| **Security** | MIT licensed, local-first processing — no proprietary drawing upload required |
| **Impact** | Most-starred repository in my portfolio; a bridge between AI and engineering CAD workflows |
| **Repository** | [github.com/Vartmor/CADLift](https://github.com/Vartmor/CADLift) |

Engineering CAD work is repetitive at the modeling stage. CADLift attacks that bottleneck by treating geometry as a compilation target: the input can be a prompt, a raster image or a legacy 2D drawing, and the output is clean, editable 3D geometry that drops straight into an existing engineering pipeline.

</details>

<summary><b>GaziAI Avatar — Real-Time Conversational 3D Avatar</b></summary>

<br/>

Interactive AI-driven 3D avatar with a Flask backend and a React / React Three Fiber frontend, wired to a real-time speech-to-text → LLM → text-to-speech loop.

| | |
| :--- | :--- |
| **Stack** | ![Flask](https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask&logoColor=white) ![React](https://img.shields.io/badge/React-61DAFB?style=flat-square&logo=react&logoColor=black) ![R3F](https://img.shields.io/badge/R3F-000000?style=flat-square&logo=threedotjs&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black) |
| **Scale** | Full voice conversation loop rendered against an animated 3D character |
| **Performance** | Streaming STT/TTS stages to keep perceived latency conversational |
| **Security** | MIT licensed; API keys stay server-side and are never exposed to the browser |
| **Impact** | End-to-end multimodal AI system: audio in, reasoning, audio and animation out |
| **Repository** | [github.com/Vartmor/GaziAI-Avatar](https://github.com/Vartmor/GaziAI-Avatar) |

The hard part of a talking avatar is not the model, it is the orchestration: capturing audio, transcribing it, reasoning over it, synthesizing speech and driving the mesh — all without the user feeling the seams. This project is my study of that pipeline.

</details>

<details>
<summary><b>BringYourSub — AI Subtitles for YouTube, Bring Your Own Key</b></summary>

<br/>

Free and open-source browser extension that generates AI subtitles for YouTube videos using the user's own OpenAI API key, with context-aware translation and a Whisper fallback when no native transcript exists.

| | |
| :--- | :--- |
| **Stack** | ![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white) ![Whisper](https://img.shields.io/badge/Whisper-412991?style=flat-square&logo=openai&logoColor=white) ![Chromium](https://img.shields.io/badge/Chromium-4285F4?style=flat-square&logo=googlechrome&logoColor=white) ![Firefox](https://img.shields.io/badge/Firefox-FF7139?style=flat-square&logo=firefoxbrowser&logoColor=white) |
| **Scale** | Cross-browser support for Chromium and Firefox |
| **Performance** | Full-transcript context passing for coherent translation instead of line-by-line drift |
| **Security** | Bring-your-own-key model — credentials stay on the user's machine; MIT licensed |
| **Impact** | Makes any YouTube video watchable in any language without a paid subtitle service |
| **Repository** | [github.com/Vartmor/BringYourSub](https://github.com/Vartmor/BringYourSub) |

Line-by-line machine translation loses the thread of a video. BringYourSub sends the full transcription as context so the translation stays coherent across the whole runtime, and falls back to Whisper when YouTube has nothing to offer.

</details>

<details>
<summary><b>RataPulse — Terminal Process Monitor in Rust</b></summary>

<br/>

Your system's pulse, right in the terminal — an htop-style Linux process monitor written in Rust with Ratatui.

| | |
| :--- | :--- |
| **Stack** | ![Rust](https://img.shields.io/badge/Rust-000000?style=flat-square&logo=rust&logoColor=white) ![Ratatui](https://img.shields.io/badge/Ratatui-7C3AED?style=flat-square) ![Linux](https://img.shields.io/badge/Linux-FCC624?style=flat-square&logo=linux&logoColor=black) |
| **Scale** | Live process table sourced directly from the Linux `/proc` filesystem |
| **Performance** | Zero-GC Rust core with a redraw loop designed for a constant refresh budget |
| **Security** | Memory-safe by construction; read-only system introspection; MIT licensed |
| **Impact** | Systems-programming deep dive — phase 1 of a 5-phase roadmap, in active development |
| **Repository** | [github.com/Vartmor/RataPulse](https://github.com/Vartmor/RataPulse) |

A deliberate exercise in low-level engineering: ownership, lifetimes, `/proc` parsing and terminal rendering, with no runtime and no garbage collector to hide behind.

</details>
